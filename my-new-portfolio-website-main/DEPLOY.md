# Deployment

This is a static HTML/CSS/JavaScript portfolio.

## Vercel
1. Push these files to the GitHub repository.
2. In Vercel, import the repository.
3. Keep the framework preset as **Other** if Vercel does not detect one.
4. Deploy from the repository root.

## Hostinger / standard web hosting
Upload the contents of this folder into the site's `public_html` directory.

The main entry file is `index.html`.
